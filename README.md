# Laman Minda

Laman maklumat kesihatan mental dan kemahiran bantu diri untuk pesakit dan keluarga.
**Unit Psikiatri & Kesihatan Mental, Hospital Serian.**

- Laman statik, dwibahasa (English lalai, BM boleh tukar), boleh dibuka tanpa internet selepas lawatan pertama.
- Tiada log masuk, tiada kuki penjejak, tiada data dihantar. Pelan pesakit disimpan di telefon mereka sahaja.
- v0.3 (29/09/2026): rupa baharu ikut reka bentuk Baya; English lalai.
- v0.2 (29/09/2026): Laman Minda digabung dengan kandungan Minda Tenang v1.0 (disemak MO 28/09/2026).
- Pautan lama Minda Tenang (`#/...`, termasuk kad QR preskripsi) dibuka ke halaman Laman Minda yang sepadan.
- Status: **DRAF**, menunggu kelulusan Ketua Jabatan. Tag `noindex` kekal sehingga diluluskan.
